# 字体目录说明（`fonts/`）

《海南大学研究生学位论文撰写规范（修订）》（海大党政办〔2023〕47 号）在封面和原创性声明页指定了以下两款字体：

| 用途 | 规范要求字体 | 常见文件名 |
| :--- | :--- | :--- |
| 封面「硕士/博士学位论文」、声明大标题 | **方正小标宋简体** | `FZXBSJW.TTF` |
| 封面信息（代码、分类号、题目、姓名、日期等） | **楷体\_GB2312** | `KaiTi_GB2312.ttf` 或 `simkai.ttf` |

由于上述字体为商业/系统授权字体，本开源仓库**不包含**任何商业字体文件。

## 自动回退与本地启用方式

1. **零配置编译**：直接编译即可，模板会自动检测系统字体；若未安装上述两款字体，将自动优雅回退到系统宋体（加粗）/ 系统楷体（或 Fandol 开源字体），**不会报错中断**。
2. **严格对齐官方字体（推荐最终提交前使用）**：
   - 将合法获取的 `FZXBSJW.TTF`（方正小标宋简体）与 `KaiTi_GB2312.ttf`（楷体\_GB2312）放入本 `fonts/` 目录中，或直接安装到操作系统字体库。
   - **Overleaf 用户**：直接将字体文件上传到 Overleaf 项目的 `fonts/` 文件夹下，重新编译即可自动识别生效，无需修改任何代码。
   - 本目录的 `.ttf / .otf / .ttc` 文件已被 `.gitignore` 忽略，不会误提交到开源仓库。
